# Twine

Twine is an agent workspace for coordinating your agents

## Development setup

- Install Xcode and point the developer tools at it: `sudo xcode-select -s /Applications/Xcode.app/Contents/Developer`. SwiftLint runs as an Xcode build plugin and crashes if `xcode-select` points at the Command Line Tools.
- The first time you build in Xcode, trust the SwiftLint plugin when prompted.
