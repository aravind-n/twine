Rust core & C ABI.

One workspace reference for Twine’s reusable application core and the C ABI that connects it to Swift. Browse either crate below, or search their APIs together.

Application core and bridge

CrateAPI reference
twine_coreDomain state, workflow orchestration, process supervision, files, and persistence. A Rust API independent of the UI and FFI.
twine_bridgeThe C ABI between core and Swift: exported functions, buffers, and ownership and safety contracts.

Both crates are generated together with cargo doc --workspace --no-deps and share Cargo’s documentation search.

For the Swift side of this boundary, see the native macOS app reference. For installation and usage, see the user guide.
